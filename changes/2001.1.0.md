# 更新日志 / Changelog

## 2001.1.0

**中文**

- 首次发布 1.20.1 版本，把 1.21.1 版的 KubeJS 联动完整移植到 Forge 1.20.1。
- 支持用脚本自定义沉浸工程的 18 种配方：合金炉、电弧炉、高炉、高炉燃料、焦炉、粉碎机、
  金属冲压机、灌装机、锯木机、发酵桶、压榨机、蒸馏塔、混合器、蓝图工作台、钟形温室、
  肥料、矿脉混合、发电机燃料。
- 新增 `IEEvents.createStructure` 事件，可在多方块结构成型前拦截。
- 提供脚本工具：`TagOutputJS`、`IngredientWithSizeJS`、`StackWithChanceJS`、
  `ClocheRenderFunctionsJS`、`MineralMixBuilder`、`GeneratorFuelHelper`。
- 产出与副产物支持标签，既可以用 `TagOutputJS`，也可以直接写 `'#forge:ingots/iron'` 这样的
  字符串；读取沉浸工程自带配方时标签与条件会原样保留，不会改写原有配方。
- 受 1.20.1 版本沉浸工程自身数据格式限制，以下写法与 1.21.1 版不同：矿脉混合改用维度限定
  而不是生物群系标签；钟形温室没有流体字段，渲染方式改为「类型 + 方块」；流体输入必须是
  流体标签；发电机燃料只能按流体标签添加。

**English**

- First 1.20.1 release: the KubeJS integration from the 1.21.1 version is now available for
  Forge 1.20.1.
- Script-defined recipes for all 18 Immersive Engineering recipe types: alloy kiln, arc furnace,
  blast furnace, blast furnace fuel, coke oven, crusher, metal press, bottling machine, sawmill,
  fermenter, squeezer, refinery, mixer, blueprint, cloche, fertilizer, mineral mix and
  generator fuel.
- Added the `IEEvents.createStructure` event, which can cancel multiblock formation.
- Added the script helpers `TagOutputJS`, `IngredientWithSizeJS`, `StackWithChanceJS`,
  `ClocheRenderFunctionsJS`, `MineralMixBuilder` and `GeneratorFuelHelper`.
- Results and by-products support tags, either through `TagOutputJS` or with the `'#forge:ingots/iron'`
  string syntax. Tags and conditions of existing Immersive Engineering recipes are preserved
  verbatim, so the mod never rewrites them.
- Because of how Immersive Engineering 1.20.1 stores its data, a few things differ from 1.21.1:
  mineral mixes are limited by dimension instead of biome tags, cloche recipes have no fluid field
  and use a render reference, fluid inputs must be tags, and generator fuel can only be added by
  fluid tag.
